# HXtra bass features

Every feature, where to find it on the HX Stomp, every setting and a demo of each is on the **[features page](https://muetze-online.github.io/hxtra-bass/web/features.html)**. Its source is [`web/features.html`](../web/features.html); it lists this fork's features first, then the ones from upstream HXtra.
